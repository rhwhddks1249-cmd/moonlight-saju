# 사주명리 천문 만세력 심층 분석 웹앱

외부 서버 통신 없이 이 컴퓨터에서 100% 로컬(오프라인)로 동작하는 정밀 사주명리 분석 웹 애플리케이션입니다.

## 주요 기능 및 분석 엔진

1. **천문학적 만세력 정밀 절기 계산 (Astronomical Algorithm)**
   - Jean Meeus 태양 황경(Solar Longitude) 정밀 공식을 통해 24절기 절입 시각을 분 단위 이하 오차로 산출합니다.
   - 입춘(立春)을 기준으로 년주를 엄밀히 구분하며, 12절(節)을 기준으로 월주를 정확하게 결정합니다.
   - 율리우스일(Julian Day Number) 기반 60갑자 일주 및 한국 표준시(동경 135도) 기준 23:30 경계(자시 보정) 시주를 산출합니다.
   - 음력/양력 상호 변환 및 윤달(閏月) 완벽 지원.

2. **사주팔자 심층 감정 (Four Pillars Analysis)**
   - **십성(十星/육친) 및 지장간**: 10천간, 12지지, 지장간(여기·중기·정기) 및 12운성(포태법) 산출.
   - **오행(五行) 에너지 밸런스**: 목·화·토·금·수 세력 점수(100점 만점 명리학 가중치) 및 **순수 SVG 오행 Radar 차트** 로컬 렌더링.
   - **신강(身强) · 신약(身弱) 판별**: 득령(得令), 득지(得地), 득세(得勢) 성취 여부 및 인비 세력 스펙트럼 게이지.
   - **용신(用神) & 희신(喜神) 솔루션**: 억부용신 및 조후용신 도출, 행운의 색상/숫자/방위/개운 아이템 추천.
   - **10년 대운(大運) 타임라인**: 성별 및 생년 음양에 따른 순행/역행 판별, 절기 시각 기반 정밀 대운수(1~10), 10개 대운 간지 및 현재 나이 대운 하이라이트.
   - **올해 세운(歲運) 분석**: 당해 연도(2026 丙午년 등) 세운 간지와 일간의 십성 상호작용 및 재물/직업/인간관계/건강운 풀이.
   - **구조화된 JSON 데이터**: 모든 분석 결과를 체계적인 JSON 형식으로 생성하며, 화면에서 즉시 열람 및 원클릭 파일 다운로드 지원.

3. **3단계 화면 흐름 연출**
   - **입력 페이지**: 이름, 성별, 생년월일, 양/음력, 윤달, 출생 시간(시간 모름 지원), 빠른 예시 데이터 입력.
   - **로딩 연출 (약 1.5초)**: 음양 태극 및 5개 오행 오비탈 구체 회전 스피너와 실시간 절기 대조 단계별 안내 메시지.
   - **결과 페이지**: 프리미엄 다크 미스틱 UI, SVG Radar 차트, 대운 타임라인, 신강신약 게이지, JSON 뷰어 모달.

## 실행 방법

### 1. 간편 실행 (권장)
- 폴더 내 **`start.bat`** 파일을 더블클릭하면 서버 실행과 함께 브라우저(`http://127.0.0.1:5000`)가 자동으로 열립니다.

### 2. 터미널에서 직접 실행
터미널에서 아래 명령어를 실행하면 로컬 서버가 시작되고 웹 브라우저가 자동으로 열립니다:

```powershell
py app.py
```

브라우저가 자동으로 열리지 않을 경우 브라우저 주소창에 `http://127.0.0.1:5000`을 입력하여 접속하세요.  
종료 시에는 콘솔 창에서 `Ctrl + C`를 누르거나 창을 닫으시면 됩니다.
